# 插件设置规范

资产发现插件的设置页位于“设置 → 插件 → 资产发现”。

## 默认收集配置

- 选择默认数据源：鹰图 Hunter 或 FOFA + 天眼查。
- 为所选数据源配置 API Host；Skill 路径可按工作区需要填写。
- 保存后，新的收集任务使用这组默认配置。

## 凭据

Hunter、FOFA 与天眼查凭据由宿主账户凭据库保存。插件前端展示配置状态，保存新值、替换与清除均使用宿主 RPC；替换及清除需要确认。密钥操作保留未保存的普通设置草稿。读取未完成或写入结果未知时停用写入，用户重新读取确认后继续。

普通设置保存时去除两端空白，以 Runtime 返回的完整配置更新页面。每个响应校验数据源、路径和配置状态；保存按钮和 Enter 键显式调用 RPC，输入法组合输入期间不提交。错误界面显示操作 ID 以关联脱敏开发日志。

## 收集操作台

收集任务、资产搜索、导入和任务筛选位于插件主界面。任务详情会显示任务记录中保存的访问模式；未记录该字段的历史任务会明确标示为未记录。
